# MedPass - Medical Clearance Status Management System

A web-based system designed to streamline and digitize the medical clearance process for students, allowing efficient tracking, record management, and role-based access for administrators and patients.

---

## Project Overview

- **Goal:** Simplify and automate medical clearance workflows  
- **Focus:** Patient record management, status tracking, and admin control  
- **Output:** Functional web system with login, dashboards, and database integration  

---

## Technologies Used

- PHP  
- MySQL  
- HTML  
- CSS
- JavaScript
- XAMPP  

---

## Problem

Manual tracking of medical clearance processes leads to delays, disorganized records, and inefficient communication between patients and administrators.

---

## Solution

MedPass provides a centralized system that enables real-time tracking, organized patient data management, and role-based access to improve efficiency and accuracy.

---

## Tools Used

- **XAMPP** - Local server environment used to run and test the system  
- **phpMyAdmin** - Managed the MySQL database, including tables and queries  
- **VS Code** - Code development, editing, and debugging  
- **Browser Developer Tools** - Tested UI responsiveness and fixed layout issues  

---

## Key Features

- User authentication (Patient & Admin)  
- Patient dashboard with clearance status tracking  
- Admin dashboard for managing records  
- Add, update, and view patient information  
- Real-time database integration  
- Organized and centralized record system
